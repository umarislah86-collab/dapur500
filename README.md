# 🍳 DAPUR 500 — Koleksi 518 Resipi Ebook Masakan Tempatan

Aplikasi web masakan editorial moden yang menyatukan **518 resipi masakan Malaysia & Asia** daripada 10 buah e-book masakan popular. 100% lengkap dengan sukatan bahan, langkah demi langkah, pemadan bahan dapur (*Fridge Matcher*), dan senarai semak interaktif.

### 🌐 Akses Pantas (Live Web App)
👉 **[https://umarislah86-collab.github.io/dapur500/](https://umarislah86-collab.github.io/dapur500/)**

Boleh dibuka di telefon pintar, tablet, atau komputer dari mana-mana sahaja di luar rumah tanpa memerlukan sebarang pemasangan!

---

## ✨ Ciri-Ciri Utama

1. **100% Data Lengkap Tanpa Placeholder**:
   - Kesemua 518 resipi mempunyai senarai sukatan ramuan dan langkah penyediaan terperinci.
2. **Mod "Peti Ais Saya" (Fridge Matcher)**:
   - Pilih bahan asas yang ada di dapur anda (cth: *ayam, telur, santan, kentang, oat*) dan sistem akan menyusun resipi yang paling sesuai secara automatik.
3. **Carian Pantas Berkuasa**:
   - Cari mengikut nama hidangan, bahan masakan, atau kategori.
   - Pintasan papan kekunci: Tekan `/` untuk terus mula menaip carian.
4. **Senarai Semak Interaktif (Checklist)**:
   - Semasa memasak di dapur, tanda bahan-bahan yang telah disediakan untuk memastikan tiada bahan tertinggal.
5. **Sokongan Dwi-Tema (Mod Gelap & Cerah)**:
   - Skim warna editorial kulinari *warm ivory* dan *obsidian charcoal* yang selesa untuk mata.
6. **Simpan Resipi & Kongsi**:
   - Simpan (*Bookmark*) resipi kegemaran anda dalam storan peranti.
   - Salin teks resipi lengkap dengan 1-klik untuk dikongsi ke WhatsApp atau Telegram.
   - Mod cetakan mesra kertas / PDF.

## 💻 Menjalankan Secara Tempatan (Local Development)

Jika anda ingin menjalankan aplikasi ini di komputer sendiri (dengan penstriman fail PDF e-book asal):

```bash
# 1. Klon repositori
git clone https://github.com/umarislah86-collab/dapur500.git
cd dapur500

# 2. Jalankan pelayan Node.js
npm start
# atau: node server.js

# 3. Buka di pelayar
http://localhost:3000
```
